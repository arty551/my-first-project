# My First Project 

Learning how to use git and webscraping 

## What's inside 

yahoo_scraper.py - scrapes the '<h3>' headers from Yahoo Finance 
port.py - scrapes Yahoo Finance for ticker symbols I'm tracking 
portfolio.pi - uses the 'yfinance' library to fetch stock data 
scraper.py - practice with BeautifulSoup4 functions 
requirements.txt. - exact python package versions for reproducing the environment 

## setup 

This project uses a python virtual environment 

```bash 
# clone the repo 
git clone https://github.com/arty551/my-first-project.git
cd my-first-project

# Create and activate a virtualenv 
python -m venv venv 
source/venv/bin/activate 

# Install Dependencies 
pip install -r requirements.txt
